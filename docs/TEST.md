# TEST.md — LateMate 통합 테스트 플랜

> **버전**: 0.1.0  
> **작성일**: 2026-05-17  
> **테스트 환경**: 실기기 2대 (주최자 A / 참여자 B) + HTTPS 환경 (배포 URL 또는 ngrok)

---

## 준비물

- 기기 2대 (A: 주최자, B: 참여자) — GPS 테스트는 실기기 필수
- 배포 URL 또는 ngrok으로 HTTPS 터널링된 로컬 서버
- Supabase 대시보드 (데이터 확인용)

---

## 시나리오 1 — 약속 생성 (기기 A)

| 단계 | 행동 | 기대 결과 | 결과 |
|------|------|-----------|------|
| 1-1 | 홈 → `약속 만들기` 클릭 | `/create` 이동 | |
| 1-2 | 약속 이름 입력 (예: "홍대 치킨") | 글자 수 카운터 표시 | |
| 1-3 | 장소 검색창에 "홍대입구역" 입력 | 300ms 후 드롭다운 표시 | |
| 1-4 | 검색 결과에서 장소 선택 | 인디고 배경으로 선택 확정 표시 | |
| 1-5 | 날짜/시간 설정 (30분~1시간 후로) | datetime-local 값 반영 | |
| 1-6 | 닉네임 입력 (예: "민준") | | |
| 1-7 | `약속 만들기 →` 클릭 | InviteShare 모달 오픈, 6자리 코드 표시 | |
| 1-8 | `링크 복사` 클릭 | "복사됐어요!" 피드백 2초 | |
| 1-9 | `약속 화면으로 →` 클릭 | AppointmentPage 진입 | |

**확인 사항**
- 헤더에 약속 이름 + 카운트다운 표시
- 참여자 1명 (나 / 주최) 표시
- 타임라인에 "민준이 참여했어요" 이벤트 기록

## 시나리오 2 — 친구 참여 (기기 B)

| 단계 | 행동 | 기대 결과 | 결과 |
|------|------|-----------|------|
| 2-1 | 복사된 링크 접속 or 홈에서 초대 코드 입력 후 `참여하기` | JoinPage 이동 | |
| 2-2 | 약속 정보 카드 확인 (제목 / 장소 / 시간) | 시나리오 1과 동일한 내용 | |
| 2-3 | 닉네임 입력 (예: "지수") | | |
| 2-4 | `참여하기` 클릭 | AppointmentPage 진입 | |
| 2-5 | 기기 A 화면 확인 (7초 내) | 참여자 목록에 "지수" 추가, 타임라인에 "지수이 참여했어요" | |

**확인 사항 (기기 B)**
- 참여자 2명 표시
- 자신은 "(나)" 배지

## 시나리오 4 — 위치 공유 (양쪽 기기) ⚠️ 실기기 필수

| 단계 | 행동 | 기대 결과 | 결과 |
|------|------|-----------|------|
| 4-1 | 기기 A: `위치 공유 시작하기 →` 클릭 | GPS 권한 요청 팝업 | |
| 4-2 | 권한 허용 | 에메랄드 "위치 공유 중 · 중지하기" 전환, live-pulse 점 | |
| 4-3 | 타임라인 확인 | "민준이 출발했어요" 이벤트 기록 | |
| 4-4 | 기기 B도 위치 공유 시작 | 동일 흐름 | |
| 4-5 | 기기 A에서 7초 대기 후 지도 확인 | 기기 B 위치에 "지수" 마커 표시 | |
| 4-6 | 기기 B에서 7초 대기 후 지도 확인 | 기기 A 위치에 "민준" 마커 표시 | |
| 4-7 | 한 기기 실제 이동 | 상대 기기에서 마커 위치 갱신 (7초 내) | |

## 시나리오 5 — ETA 및 상태 판단 ⚠️ 실기기 필수

| 단계 | 행동 | 기대 결과 | 결과 |
|------|------|-----------|------|
| 5-1 | 위치 공유 시작 후 30초 대기 | 참여자 카드에 "N분 후 도착 예상" 표시 | |
| 5-2 | Supabase `participant_locations` 확인 | `eta_seconds`, `status` 값 업데이트 | |
| 5-3 | 약속 시간을 5분 후로 짧게 설정 후 재테스트 | ETA > 약속시간+5분 → `status: late`, 카드 빨간색 | |
| 5-4 | `late` 전환 후 타임라인 확인 | "지각 예상이에요" 이벤트 1회만 기록 | |
| 5-5 | 약속 장소 100m 이내 이동 | `status: arrived`, 카드 파란색, 타임라인 "도착했어요" | |

## 최종 체크리스트 (T-060)

```
[ ] 약속 생성 → Supabase appointments 레코드 확인
[ ] 참여자 등록 → participants 레코드 확인
[ ] 닉네임 중복 에러 표시
[ ] 세션 복구 (링크 재접속)
[ ] 위치 공유 시작 → participant_locations upsert 확인
[ ] 지도 마커 표시 (7초 내)
[ ] ETA 계산 → eta_seconds 업데이트 (30초 내)
[ ] StatusBadge 상태 전환 (on_time / late / arrived)
[ ] 타임라인 이벤트 4종 (JOINED / DEPARTED / LATE_ALERT / ARRIVED)
[ ] BottomSheet 드래그 스냅
[ ] iOS Safe Area 레이아웃 (홈바 겹침 없음)
[ ] 오프라인 배너
[ ] 위치 권한 거부 처리
[ ] 브라우저 새로고침 후 세션 유지
```

---

> GPS / 실기기 필수 항목(시나리오 4·5·9)은 배포 후 실기기에서 직접 테스트.  
> 나머지(시나리오 1·2·3·6·7·8)는 PC 브라우저로 검증 가능.
